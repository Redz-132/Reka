# REKA Hero 2D

Tampilan utama memakai latar kota 2D panorama tanpa panel teks bawaan, peta Indonesia dengan label Bandingkan Kota, dan kartu-kartu pilar HTML yang terpisah. Tidak ada renderer WebGL atau model 3D yang dimuat.

## Isi paket
- `index.html` memuat situs REKA dan fitur interaktifnya.
- `assets/reka-hero-city-2d.webp` adalah latar kota 2D yang menyatu dengan area hero.
- `assets/reka-map-2d.webp` menampilkan peta Indonesia dengan label Bandingkan Kota menggantikan label Jakarta.
- Kartu pratinjau pilar memakai empat gambar 2D terpisah dan markup HTML, bukan satu gambar tangkapan layar.
- Kartu pilar membuka panel detail dengan transisi 2D. Kartu Paspor tetap datar tanpa efek tilt 3D.

## Menjalankan
Ekstrak folder `REKA`, lalu buka `index.html` atau jalankan lewat Live Server. Situs tidak membutuhkan dependensi eksternal.
